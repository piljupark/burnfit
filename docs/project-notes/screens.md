# 화면 짜임

2026-10-11 기준 코드에서 정리했다. 각 화면은 **위에서 아래 순서**로 적었다. 숫자는 높이·크기(pt), `16/500`은 글자 크기/굵기. 부품 설명은 [컴포넌트 목록](components.md), 색·간격 규칙은 [디자인 시스템](../design-system.md).

## 0. 길 찾기

### 이름 있는 경로 (`lib/core/constants.dart` `AppRoutes`, `lib/main.dart`)

| 경로 | 화면 |
|---|---|
| `/` | `SplashScreen` (시작) |
| `/login` | `LoginScreen` |
| `/pending` | `PendingApprovalScreen` |
| `/onboarding/basic` · `/onboarding/body` | 회원 첫 입력 두 단계 |
| `/member/home` · `/trainer/home` · `/admin/home` | 역할별 탭 화면 |

그 밖의 화면은 모두 `MaterialPageRoute`로 연다.

### 첫 화면 정하기 (`startRouteFor`, `lib/core/app_routing.dart`)

거절 → 로그아웃 · 대기 → `/pending` · 관리자 → 관리자 홈 · 트레이너 → 트레이너 홈 · 회원 → 생년월일 없으면 `/onboarding/basic`, 있으면 회원 홈.

앱 전체를 `AccountStatusListener`가 감싸서, 쓰는 중에 계정 상태가 바뀌면 바로 옮기고 토스트를 띄운다 (승인 → 역할 홈, 다시 대기 → `/pending`, 거절 → 로그아웃 후 `/login`).

### 아래 탭 (`AppNavBar`)

| 역할 | 탭 | 비고 |
|---|---|---|
| 회원 | 홈 · 운동 · PT · 마이 | 운동 탭이 아닐 때 휴식 타이머 막대를 탭 바 위에 띄운다 |
| 트레이너 | 홈 · 일정 · 회원 · 식단 · 마이 | 피드백할 식단이 있으면 식단 탭에 점 (회원 탭에는 점 없음) |
| 관리자 | 홈 · 회원 · 트레이너 · 마이 | |

모두 `IndexedStack`이고, 탭을 옮길 때 그 탭을 다시 불러온다.

### 푸시 알림을 누르면

| 알림 | 회원 | 트레이너 |
|---|---|---|
| 피드백 | 홈 → 피드백 화면 | — |
| PT 일정 | PT 탭 | 일정 탭 |
| 공지 | 공지 목록 | 공지 목록 |
| 운동 (마치기 알림) | 운동 탭 | — |
| 식단 올라옴 | — | 식단 탭 |

### 머리 모양

- `AppHero` — 탭 화면 맨 위. 44 줄에 28 제목 + 오른쪽 아이콘.
- `AppScreenHeader` — 하위 화면. 기본(뒤로 + 왼쪽 제목, 트레이너·관리자) · `.centered`(56, 가운데 17/500, 회원) · `.large`(뒤로 줄 아래 28 큰 제목, 가입·알림·공지·관리자 목록).

## 1. 공통

### 시작 `SplashScreen` — `lib/screens/splash_screen.dart`
- 빈 바탕만. 0.8초 넘게 걸리면 아래 로딩 점.
- 사용자 정보를 못 읽으면 아래 안내 + '다시 시도'(주) · '로그아웃'.

### 로그인 `LoginScreen` — `lib/screens/login_screen.dart`
- 가운데 제목. 이 기기에 저장된 계정이 있으면 '다시 오셨네요' + 계정 카드(회색 반경 20 · 센터 16/500 · '역할 · 이메일' 13 · 흰 알약 '바꾸기') + 비밀번호. 없으면 '로그인' + 이메일 · 비밀번호(보기 단추).
- 비밀번호 아래 '비밀번호를 잊었어요' → 재설정 시트.
- 아래 고정(키보드 따라 올라옴): '로그인' → '다른 계정으로 로그인' / '처음이에요 · 가입하기'.
- 거절된 계정이면 확인 창으로 계정 삭제 안내.

### 가입 `RegisterFlowScreen` — `lib/screens/register_flow_screen.dart`
- 한 화면에 하나씩. 회원·트레이너: 역할 → 센터 → 계정 → 확인 → 승인 대기. 관리자: 역할 → 계정 → 센터 열기 → 관리자 홈.
- 머리: 뒤로 44 + 진행 칸(4 높이, 지난·지금 주황) + '1/3'. 역할 단계는 진행 칸 없음.
- 역할: '어떤 계정을 만들까요?' + 줄 3개(아이콘 상자 + 설명) + '이미 계정이 있어요 · 로그인'.
- 센터: 검색 + 센터 줄(고르면 주황 체크).
- 계정: 이름 · 이메일 · 비밀번호 + 규칙 줄 '8자 이상 · 지금 5자'.
- 확인: 회색 카드 56 줄 4개(누르면 그 단계로) + 안내 줄.
- 센터 열기(관리자): 설정 코드 · 센터 이름 · 주소(선택).
- 아래 고정: '다음' / '가입 신청' / '센터 열기'. 뒤로는 앞 단계로.

### 승인 대기 `PendingApprovalScreen` — `lib/screens/pending_approval_screen.dart`
- '승인 대기' → '가입 승인 대기 중' → 센터 이름이 들어간 안내.
- 아래: '새로고침'(주) · '로그아웃'.

### 회원 첫 입력 `OnboardingBasicScreen` · `OnboardingBodyScreen` — `lib/screens/member/onboarding_screens.dart`
- 위 줄(이전 · 오른쪽 '로그아웃') → 단계 막대 → 28 제목 + 16 설명 → 입력 → 아래 고정 행동.
- 1단계: 생년월일 8자리 + 성별 → '다음'.
- 2단계: 키·체중, 골격근량·체지방(2열), 목표 → '시작하기' / '나중에 입력'.

### 알림 `NotificationsScreen` — `lib/screens/common/notifications_screen.dart` (회원·트레이너)
- 홈 머리의 종(안 읽은 것 있으면 맥박 점)에서 연다.
- 큰 제목 '알림' + 'N일 동안 보관돼요' → 줄(아이콘 상자 40 · 제목 16/500 · 내용 15 · 시각 13 · 새 알림 주황 점).
- 밀어서 삭제, 열면 모두 읽음, 누르면 푸시와 같은 곳으로. 비면 흔들리는 종.

### 공지 목록 `NoticeListScreen` · 공지 `NoticeDetailScreen` — `lib/screens/common/`
- 목록: 큰 제목 '공지사항' → 중요 공지(연한 주황 카드) → 일반 줄(핀 · 새 글 점 · '10월 8일 · 중요 · 수정됨'). 열면 모두 본 것으로.
- 본문: 뒤로 → '중요 공지' 14 · 제목 24/500 · 보조 줄 · 선 · 내용 16 → 아래 회색 '목록으로' 56.
- 홈 공지 줄 `NoticeHomeBanner`: 회원·트레이너 홈 머리 아래 최신 공지 한 줄. 중요 공지는 공지마다 한 번 시트로.
- 마이 '공지사항' 줄 `NoticeMenuRow`: 새 글 있으면 '● 새 글 n'.

## 2. 회원

### 홈 탭 `MemberCalendarScreen` — `lib/screens/member/member_calendar_screen.dart`
- 공통 위: '홈' + 종 → 오늘 · 캘린더 · 기록 고르기 → 공지 줄.
- **오늘**: PT 막대(64 주황 · 'PT N회 남음' · '예약 | 일정') → 바로가기 4×2(운동 기록 · 식단 · 피드백 · 영양 가이드 · PT 일정 · 운동 통계 · 인바디 · 휴식 타이머) → 이번 주 카드(불꽃 'N일째 운동 중' · 월~일, 누르면 캘린더로) → '오늘' 줄.
  - '오늘' 줄(시각 44 · 제목 · 보조): 오늘 PT 예약('PT' · 트레이너 · 50분 · 완료, → PT 탭)과 오늘 저장한 개인 운동('개인 운동' · 부위 · N세트 · 볼륨 · 운동 시간, 시각은 시작 시각, → 운동 탭)을 시각 순으로. 둘 다 없으면 '오늘 예정된 일정과 운동 기록이 없습니다'. 트레이너가 남긴 PT 운동 기록은 PT 예약 줄과 겹치므로 넣지 않는다.
- **캘린더**: 월 이동 → 달력(PT 완료 · PT 예약 · 개인운동 점) → 띠 → 고른 날 머리 → 그날 기록 줄(PT 운동 · 개인운동 · PT 예약 · 식단 · 피드백).
- **기록**: 이번 달 기록 있는 날을 최근부터.

### 운동 탭 `MemberWorkoutScreen` — `lib/screens/member/member_workout_screen.dart`
- 머리: '오늘 운동'(다른 날은 '10월 7일 운동', 고칠 때 '운동 수정') + 날짜 고르기.
- '● 운동 중 · 32분'(시작만 했으면 '취소') → 요약 3칸(종목 · 세트 · 볼륨) → 빈 카드(바벨 · 회색 '운동 시작') 또는 종목들(펼친 것: 이름 · 지난 기록 비교 · 메모 줄(있으면, 누르면 고치기) · 세트 표 52 줄 · 완료 원 36 · '+ 세트 추가' / 접힌 것: '4세트 · 2/4') → 점선 '종목 추가' → (고칠 때) '운동 시간' 줄 → 메모 → 띠 → '저장된 기록' 카드.
- 맨몸 운동(푸시업 · 풀업 · 플랭크 등, `ExerciseData.bodyweight`)은 무게 칸 없이 '회' 한 칸. 버티는 운동(`ExerciseData.timed`)은 '초'. 종목 설명 시트 설정 탭 '무게 칸'으로 중량을 더할 수 있다. 비교 줄은 무게 대신 최고 횟수(초)로.
- 키패드: 세트 칸 밖을 누르거나, 목록을 밀거나, 완료 원을 누르면 내려간다 (다른 세트 칸을 누르면 그 칸으로 옮겨 간다).
- 진동: 세트 완료 · 세트 추가 · 탭 바꾸기 · 저장 완료 · 경고 (마이 '진동'으로 끔).
- 아래 고정: 휴식 막대(검정 64 · '+30초' · '건너뛰기') + '운동 마치기' / '수정 저장'.
- 휴식 타이머: '끝나는 시각' 기준이라 다른 앱에 가 있거나 화면을 꺼도 흐른다. 10초 전에 한 번, 끝나면 세게 세 번 진동. 앱이 뒤에 있으면 기기 알림('휴식 10초 남음' · '휴식 끝')으로 알린다. 휴식 중에는 안드로이드는 알림 센터에, 아이폰(16.2+)은 잠금 화면 · 다이내믹 아일랜드에 줄어드는 남은 시간을 띄운다 (검정 바탕 · 주황 진행 막대, 끝 시각이 지나면 '휴식 끝'). 아이폰은 설정에서 실시간 현황을 꺼 두면 보이지 않는다.
  - 안드로이드 14+에서 '알람 및 리마인더' 권한이 꺼져 있으면 처음 한 번 '휴식 끝 알림' 시트로 허용을 권한다 (꺼 두면 앱이 뒤에 있을 때 알림이 몇 분 늦을 수 있다).
- 임시저장, 30초마다 시간 갱신, 세트마다 10분 뒤 알림 다시 맞춤, 앱 열 때 못 마친 운동 자동 저장(`workout_auto_save.dart`). 저장하면 완료 화면.
- 종목 설명 시트(시안 03): 카드 이름을 누르면 '설명' 탭, ⋯를 누르면 '설정' 탭으로 열린다. 종목 고르기 줄 끝 ⓘ로도 연다(설명 · 기록만).
  - 설명: 근육 그림(앞 · 뒤, 주 근육 주황 · 보조 연주황, 여성 회원은 여성 몸) → 도구 · 기록 방식 · 난이도 3칸 → 주 근육 · 보조 칩 → 운동 방법 01~05 → '검수 전' + 출처. 직접 추가한 종목은 '설명이 없어요' 카드 + 부위 · 도구 · 기록 3칸.
  - 기록: 최고 무게 · 하루 최고 볼륨 2칸(맨몸은 횟수, 버티기는 초, 유산소는 지표 · 분) → 최근 5번 막대(마지막 주황) → 지난 기록 줄(날짜 · '4세트 · 24kg × 10' · 볼륨).
  - 설정: 메모 → 휴식 시간(− 90초 +, 15초씩) → 무게 칸 스위치 → 무게 단위 kg | lbs → '이 종목 빼기'.
- 시트: 종목 고르기 · 종목 설명 · 종목 메모 · 운동 시간 · 날짜.

## 정리할 것

- 경로 상수 `trainerLogin`·`adminLogin`(`lib/core/constants.dart`)은 어디서도 쓰지 않는다.
- `lib/widgets/center_list_row.dart` 주석에 '로그인 센터 선택 시트'가 남아 있다 — 지금은 가입 화면의 센터 단계에서만 쓴다.
