종목 설명 화면

근육 그림은 muscle_map 부품, 운동 방법은 공공 소유 운동 자료 묶음(free-exercise-db)을 번역해 앱 안에 넣는다고 가정한 화면이에요. 종목을 바꿔 보거나 시트 안 탭을 눌러 보세요.

근육 그림은 부품의 대략적인 모습을 흉내 낸 것이에요. 실제 그림은 부품에 들어 있는 몸 그림이 나와요.
