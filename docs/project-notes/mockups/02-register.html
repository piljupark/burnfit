가입 화면 재디자인 안

로그인 정한 안(D+C)에서 역할 고르기가 빠졌으니, 가입이 그 일을 맡아야 해요. 같은 토큰과 부품으로 단계형과 한 화면형 두 안을 그렸어요.

지금 가입 화면에서 걸리는 점

register_form.dart · admin_register_screen.dart 기준

  • 역할을 로그인 화면이 정해요가입 링크가 로그인에서 고른 역할로 화면을 고르는데, 정한 로그인 안에는 역할이 없어요. 가입 첫 화면에서 골라야 해요.
  • 제목·버튼 말이 제각각'회원가입' · '트레이너 등록' · '관리자 등록', 버튼은 '가입 신청'과 '등록'이에요.
  • 센터 검색은 두 글자부터빈 칸일 땐 아무 목록도 없어서 무엇을 쳐야 할지 몰라요. 로그인 시트는 처음부터 목록을 보여 줘 서로 달라요.
  • 센터가 화면 아래쪽 묶음키보드가 올라온 채 스크롤해 내려가야 하고, 검색 결과가 폼 안에서 늘었다 줄어 화면이 흔들려요.
  • 비밀번호 규칙이 안내 문구에만'8자 이상 입력해주세요'가 입력칸 안 흐린 글자라 치기 시작하면 사라져요. 보기 단추도 없어요.
  • 누가 승인하는지 미리 모름가입 신청 뒤에야 승인 대기 화면이 나오고, 그 화면도 '관리자가 검토하고 있습니다'라 어느 센터인지 안 보여요.
  • 센터 미선택은 토스트'센터를 선택해주세요'가 위에 잠깐 떴다 사라져요.
  • 관리자 설정 코드가 맨 끝코드가 없는 사람도 이름·이메일·비밀번호를 다 채운 뒤에야 막혀요.

추천: 가 단계형. 가입은 한 번뿐이라 한 단계 늘어도 부담이 작고, 센터 고르기를 화면 전체로 쓰면 '어느 센터 관리자가 승인하는지'를 확인 화면과 승인 대기 화면까지 이어서 보여 줄 수 있어요. 관리자 설정 코드를 미리 확인하려면 서버에 '코드 확인' 함수가 하나 더 있어야 해요. 없으면 지금처럼 마지막에 확인돼요.
